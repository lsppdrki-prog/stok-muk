Cara Singkat Menghubungkan:
  1. Buka Google Sheets → menu Extensions > Apps Script.
  2. Tempel kode dari file google_apps_script_muk.gs lalu klik Deploy > New deployment (Web app).
  3. Atur Who has access ke Anyone, lalu salin Web app URL ke kotak di atas.
